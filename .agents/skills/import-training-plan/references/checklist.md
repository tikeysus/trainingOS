# Import Checklist

- Source document and source identifier retained
- Stable plan identity and revision history defined
- Dates, timezone, distance, duration, and pace units explicit
- Optional, alternate, and rest sessions represented
- Ambiguities reported instead of guessed
- Preview covers create, update, unchanged, warning, and reject outcomes
- Transaction and rollback behavior defined
- Re-import and revised-import tests prove idempotency
- Fixtures contain no personal health or location data
